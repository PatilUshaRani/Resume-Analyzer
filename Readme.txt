Recruiters often review resumes very quickly, which increases the chances of qualified candidates being overlooked.
Students also face several difficulties while preparing resumes:
Identifying the right skills and keywords
Writing clear and impactful project descriptions
Maintaining a professional structure and tone
Matching their resume with specific job requirements
To address these challenges, this project provides an AI-driven solution that analyzes resumes, detects missing skills, and offers suggestions for improvement.

🏗️ Project Architecture

The system consists of two main modules:

1️⃣ Candidate Module (Resume Analyzer)
2️⃣ Admin Module (Recruiter Dashboard)

Both modules work together to create a smarter and faster recruitment process.

👩‍💻 Candidate Side – Resume Analyzer

The Candidate Module allows job seekers to upload their resume and receive instant feedback.

Features

Upload resume in PDF format
Automatic extraction of Name, Email, and Phone
ATS Compatibility Score
Skill Match Analysis
Missing Skills Detection
AI-generated professional summary
Skill comparison visualization
Job role recommendations
Salary prediction
Learning resources for missing skills
Voice-based resume reader
This helps candidates understand their strengths, weaknesses, and areas for improvement.

🏢 Admin Side – Recruiter Dashboard

The Admin Panel is designed for recruiters to efficiently manage the resume screening process.

Features
Upload Job Description
Upload multiple resumes
AI-based candidate ranking
Identify top candidates
Generate interview questions
Predict candidate training time
Generate automated interview email templates
This helps recruiters save time and improve the candidate selection process.

⚙️ Technology Stack
Component	Technology
Programming Language	Python
Frontend	Streamlit
Resume Matching	TF-IDF
Machine Learning	Scikit-learn
Text Processing	NLP Techniques
File Processing	PDF Parsing Libraries

🔄 System Workflow
Candidate Flow
Candidate uploads resume (PDF)
System extracts resume details
AI analyzes skills and experience
Resume score and suggestions are generated
Recruiter Flow
Recruiter uploads a job description
Multiple resumes are uploaded
System compares resumes with job requirements
Candidates are ranked automatically
